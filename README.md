# a2s-discord-status-bot
A simple discord bot that shows the name,map and playercount of a game server on voice channels, mostly intended for source engine games but *should* work with any game that supports A2S

Features:
- Users can react to the emoji to force a refresh of the message
- Cooldown to prevent people from spamming the bot
- Autorefresh
- Simple custom emoji
- Super low resource usage due to simplicity
